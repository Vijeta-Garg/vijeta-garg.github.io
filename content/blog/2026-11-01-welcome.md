Hi! This is a **sample post**. Replace it with your first real one, or delete this file.

## How to write a new post

1. Copy this file inside `content/blog/` and rename it, e.g. `2026-12-05-my-first-conference.md`.
2. Change the lines between the `---` marks at the top:
   - **title**: the post title
   - **date**: written as `YYYY-MM-DD` (posts are sorted newest first)
   - **summary**: one sentence shown on the blog list
   - **tags**: separated by commas (optional)
   - **cover**: an optional picture for the blog list, e.g. `content/blog/images/czech-poster.jpg`
3. Write the post below the second `---` in Markdown: `**bold**`, `*italic*`, `## Heading`, `- bullet`, `[link](https://...)`.
4. Commit and push. The post appears on the site automatically.

## Adding pictures

Put images in `content/blog/images/` and add them to a post like this:

```
![Caption text](content/blog/images/my-photo.jpg)
```

> Tip: start a file name with `_` (for example `_draft-idea.md`) to keep it as a draft that doesn't show up on the site.
